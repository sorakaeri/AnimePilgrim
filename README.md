## 애니메이션 성지순례 가이드 사이트
HTML5 / CSS3 기반 정적 멀티페이지 웹 사이트

## 🗺️ 사이트맵 및 정보 구조
```python
📁 AnimePilgrim
├── index.html    # 홈페이지
├── gallery.html  # 각종 성지순례 사진들
├── article.html  # 성지순례 팁
└── contact.html  # 문의 폼
```
## 🎨 선택한 테마와 디자인 의도
시작적으로 보기 편하게 하기 위해 하늘색을 테마로 하여 제작하였고
라벤더 블루라는 색상을 바탕으로 하늘색과 진한 네이비 그리고 파란색을 추가하여
애니메이션 만화 특유의 몽환적인 느낌을 살리는 것을 의도하였습니다. 

## 🎯 폼 유효성·접근성 고려 사항

### 시각적 접근성
- 적절한 색상 대비 (라벤더 블루 배경에 흰색 텍스트)
- 충분한 글자 크기와 여백 사용
- 오류 상태를 색상뿐 아니라 아이콘으로도 표시

### 폼 유효성 검사
- 필수 입력 필드 명확히 표시 (* 기호 사용)
- 실시간 피드백 제공
- 오류 메시지는 명확하고 구체적으로 표시
